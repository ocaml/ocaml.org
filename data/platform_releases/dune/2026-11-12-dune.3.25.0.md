The Dune team is pleased to announce [the release of dune 3.25.0](https://github.com/ocaml/dune/releases/tag/3.25.0).

Highlights of this release include:

## Breaking changes

- Actions no longer see the shared install staging area (`_build/install/<context>/{bin,lib,lib/stublibs}`) on `PATH`, `OCAMLPATH` and `CAML_LD_LIBRARY_PATH`. An action's environment only contains the packages it declares with `(deps (package <pkg>))` (and their library closure, see below). Actions that rely on packages being visible (such as tests that `#require` the package under test from an mdx block, steps that run `ocamlfind`, a nested `dune` build, or load a bytecode stub library) must now declare the package dependency explicitly. [ocaml/dune#14373](https://github.com/ocaml/dune/pull/14373), [ocaml/dune#16617](https://github.com/ocaml/dune/pull/16617).

- The `:` character is now rejected in context names, to ensure they remain portable path components. [ocaml/dune#16085](https://github.com/ocaml/dune/pull/16085).

- Generated files are now read-only even with Dune language versions before 2.4, regardless of whether the shared cache is enabled. Executable permissions are preserved. [ocaml/dune#16388](https://github.com/ocaml/dune/pull/16388)

- In dune-project, (warnings (duplicate_deps ..)) requires a dune lang version of 3.22, instead of 3.18.1. [ocaml/dune#5696](https://github.com/ocaml/dune/pull/5696).

- `(env (env-vars ...))` in a `(context ...)` stanza of `dune-workspace` now takes precedence over the root `env` stanza, as documented. This affects commands such as `dune exec`; rules already used the documented order. [ocaml/dune#16290](https://github.com/ocaml/dune/pull/16290).

## Features

- Added command, subcommand, and flag completion in the command line. Supported shells are `bash`, `zsh`, `pwsh`, and `fish`. See `dune completion [shell] --help`. [ocaml/dune#14779](https://github.com/ocaml/dune/pull/14779), [ocaml/dune#15334](https://github.com/ocaml/dune/pull/15334).

- Tab completion for `dune promote` now lists pending promotion files. [ocaml/dune#5338](https://github.com/ocaml/dune/pull/5338).

- Add build time information to watch mode. [ocaml/dune#15384](https://github.com/ocaml/dune/pull/15384).

- Display build duration and average process parallelism in the status line for batch builds. [ocaml/dune#15564](https://github.com/ocaml/dune/pull/15564).

- Add `(flags ...)` to the `ocamllex` and `ocamlyacc` stanzas to pass custom options to parser generators. [ocaml/dune#15907](https://github.com/ocaml/dune/pull/15907).

- Starting with Dune language 3.25, restrict sandboxed actions on Linux systems with Landlock ABI 3 or newer from writing outside their sandbox, temporary directory, action-trace directory, and `/dev`. Set `DUNE_CONFIG__LANDLOCK=disabled` to opt out. [ocaml/dune#15858](https://github.com/ocaml/dune/pull/15858).

## Fixes

- `$ dune rpc build` invocations no longer queue. All build requests are built in parallel. Watch servers started by `$ dune exec --watch` can now also handle forwarded build and runtest requests. [ocaml/dune#14954](https://github.com/ocaml/dune/pull/14954). `dune rpc build` also now exits with the proper code on completion. [ocaml/dune#15341](https://github.com/ocaml/dune/pull/15341).

- Portable lock directories now select one package version across all requested platforms, and fail when no common version exists. [ocaml/dune#15982](https://github.com/ocaml/dune/pull/15982).
