We have the pleasure of celebrating the anniversary of the first
powered flight in Europe by announcing the release of OCaml 5.5.2.

OCaml 5.5.2 fixes various minor security issues, two rare miscompilations, a
configuration issue with future versions of macOS, and one runtime
events library issue.

Overall, if you were already using any versions of OCaml 5.5,
we are advising you to switch to OCaml 5.5.2 .

The full list of changes can be found in the full changelog.

---

## Installation Instructions

The base compiler can be installed as an opam switch with the following
commands:

```bash
opam update
opam switch create 5.5.2
```

The source code for the release is also directly available on:

- [GitHub](https://github.com/ocaml/ocaml/releases/download/5.5.2/ocaml-5.5.2.tar.gz)
- [OCaml archives at Inria](https://caml.inria.fr/pub/distrib/ocaml-5.5/ocaml-5.5.2.tar.gz)

### Fine-Tuned Compiler Configuration

If you want to tweak the configuration of the compiler, you can switch to the
option variant with:

```bash
opam update
opam switch create <switch_name> ocaml-variants.5.5.2+options <option_list>
```

where `<option_list>` is a space separated list of `ocaml-option-*` packages.
For instance, for a `flambda` and `no-flat-float-array` switch:

```bash
opam switch create 5.5.2+flambda+nffa ocaml-variants.5.5.2+options ocaml-option-flambda ocaml-option-no-flat-float-array
```
