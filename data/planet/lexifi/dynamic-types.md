<p>Thanks to an ongoing work by Jacques Le Normand, there is some hope to see <a href="https://en.wikipedia.org/wiki/Generalized_algebraic_data_type"><strong>Generalized Algebraic Datatypes</strong></a> (GADTs) in OCaml soon, so it’s time to get familiar with them! In this post, I’ll show how to use this new feature to represent OCaml types at runtime and define generic type-driven operations.</p>
