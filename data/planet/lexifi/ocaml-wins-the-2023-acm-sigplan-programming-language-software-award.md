<p>On June 19, 2023, it was announced that the <a href="https://ocaml.org">OCaml project</a>
received the 2023 ACM SIGPLAN Programming Language Software Award. Notices of
the award are available at <a href="https://www.sigplan.org/Awards/Software">https://www.sigplan.org/Awards/Software</a> and
<a href="https://ocaml.org/news/sigplan_announcement">https://ocaml.org/news/sigplan_announcement</a>.</p>
<p>The award is given in recognition of software systems that impact both academia
and industry. Past recipients include the V8 Javascript engine, the LLVM
compiler toolkit, the Glasgow Haskell Compiler (GHC), the GNU Compiler
Collection (GCC), the Coq proof assistant (itself written in OCaml) and the
CompCert verified compiler (also partly written in OCaml)<sup><a href="https://www.lexifi.com/blog/ocaml/index.xml#fn:1" class="footnote-ref" role="doc-noteref">1</a></sup>. Clearly, OCaml is
in very good company!</p>
